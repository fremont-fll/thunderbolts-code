# Our robot programs

Pybricks programs for our team, backed up with **Pybricks Sync** (see the tool's README for setup).

- `programs/<name>.py` is the program exactly as exported from Pybricks Code. Use **Download** in Pybricks Sync to load the programs back into Pybricks Code.
- `programs/<name>.words.py` is a readable copy of the Python inside, written automatically on every upload. **Don't edit it.** Use it to see what changed in a commit.
- Each check on GitHub confirms the two still match.
